# Screenshots

This directory contains screenshots that document the CyberSecurity-HomeLab build process.

Screenshots should be used to support the technical documentation, not replace it.

Planned screenshot categories include:

- Proxmox configuration
- VM settings
- FortiGate interfaces
- FortiGate firewall policies
- Ubiquiti switch configuration
- Ubuntu Server configuration
- DShield Honeypot status
- Backup and snapshot evidence

Before adding screenshots, sensitive information such as public IP addresses, serial numbers, usernames, tokens, and passwords should be removed or blurred.
