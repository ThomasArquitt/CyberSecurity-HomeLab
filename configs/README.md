# Configuration Files

This directory contains sanitized configuration files and configuration examples used throughout the CyberSecurity-HomeLab project.

Configuration files are organized by technology.

Planned subdirectories include:

- fortigate/
- proxmox/
- ubuntu/
- ubiquiti/

Only sanitized configuration files should be stored in this repository.

Sensitive information such as passwords, API keys, VPN secrets, serial numbers, public IP addresses, and other confidential data should never be committed.
