# Repository Standards

Documentation within this directory follows these principles:

- Document the production environment.
- Explain design decisions, not just configuration.
- Record lessons learned during implementation.
- Keep documentation synchronized with infrastructure changes.
- Remove or sanitize sensitive information before publication.
