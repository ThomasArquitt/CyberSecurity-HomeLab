# Project Overview

## Purpose

The CyberSecurity-HomeLab project is an enterprise-inspired home laboratory built to develop practical experience with systems administration, networking, virtualization, Linux, and cybersecurity technologies.

The primary goal of this project is to bridge the gap between theoretical knowledge and real-world implementation by designing, deploying, documenting, and maintaining a segmented network environment using technologies commonly found in enterprise IT infrastructures.

---

## Project Objectives

- Build and manage a virtualized infrastructure using Proxmox VE.
- Design and implement a segmented network using VLANs.
- Configure and manage a FortiGate firewall.
- Configure and manage a Ubiquiti managed switch.
- Deploy and administer Ubuntu Server.
- Deploy and operate a DShield Honeypot.
- Practice infrastructure backup and disaster recovery.
- Document all technical decisions and implementation steps.
- Continuously expand the lab with additional enterprise technologies.

## Project Philosophy

This project is being built using an incremental approach. Every major change is documented, tested, and backed up before progressing to the next phase.

The objective is not only to build a functional home lab, but also to develop engineering practices that emphasize documentation, repeatability, change management, and continuous learning.
