# Project Status

## Current Production Status

The CyberSecurity-HomeLab has been successfully migrated from an ISP gateway/router deployment to an enterprise-style FortiGate-managed network architecture.

The ISP gateway was removed from the routing path, and the ONT is now connected directly to FortiGate WAN1.
