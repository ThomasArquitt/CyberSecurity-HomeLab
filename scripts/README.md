# Scripts

This directory contains scripts developed for the CyberSecurity-HomeLab project.

The goal of this directory is to automate repetitive administrative tasks and document practical scripting skills.

Future scripts may include:

- Bash automation
- PowerShell automation
- Python utilities
- Backup scripts
- Log collection
- Health checks
- VM management
- Security auditing

All scripts should include comments explaining their purpose, requirements, and expected output.
